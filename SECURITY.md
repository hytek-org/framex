# Security Policy

## Supported Versions

The latest minor release of FrameX receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.1.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within FrameX, please do not create a public issue. Instead, report it via one of the following methods:

- **Email:** Send details to your security or maintainer email (e.g., `support@hytek.org.in`).
- **GitHub Security Advisories:** Use the "Report a vulnerability" tab on the repository.

**What to expect:**
- You can expect an acknowledgment of your report within **48 hours**.
- If the vulnerability is accepted, we will work on a patch and coordinate a disclosure timeline with you before publishing a fix.
